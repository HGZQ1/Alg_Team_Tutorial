# 三角测量 
为了大家的脑细胞着想，我就假设一个简单的模型。
我们先建立一个坐标系，设左相机的光心为原点o，右相机光心则在（B,0,0）,B就是基线距离。空间中的一点物体P是(X,Y,0)，即P跟两个相机的光心在同一水平面上。
于是我们就可以得到这个简单的三角形几何模型。

根据小孔成像，P在左图成像坐标：x1 = f *(X/Z)

右图由于相机中心右移了B，P相对的横坐标变为了(X-B),所以右图小孔成像横坐标x2= f*((X-B)/Z) 

推导很简单就是相似三角形 

视差d = x1-x2 = fx/Z - (fx-fB)/B = fB/Z 
故可推导出：Z = fB/d 

所以简单判断就是: 视差越大 → 物体越近;  视差越小 → 物体越远 


# 针孔相机模型 

**针孔相机模型描述了一个三维空间点，经过相机光心投影后，如何变成图像上的二维像素点。**

<img src="https://github.com/NeoZng/vision_tutorial/raw/main/Image_base/frontimagesmallhole.png" alt="D435i" style="width: 400px; height: 300px;">  

在初中物理时都学过小孔成像模型，针孔相机模型跟它相似，先来讲解什么是针孔相机： 
```text 
想象一个黑盒子，盒子前面只有一个非常小的孔，光线从物体出发 

物体
 ●
  \
   \
    \
     ●  ← 小孔
      \
       \
        \
         ● ← 图像     
``` 
由于所有光线都经过这个小孔，因此：**这个小孔就可以近似看作相机的光心（Camera Center / Optical Center）。** 

当然，我们正常的相机当然不是只有一个孔，然而每个光感单元体积很小可以近似看作为一个孔。 
从上图来看，连接XcO,可以很容易的看到两个相似三角形△Opx、△OPXc 和△Ocx、△OZcXc，设空间中的点P = (Xc,Yc,Zc)。
- Xc：点在相机坐标系中的左右位置；
- Yc：点在相机坐标系中的上下位置；
- Zc：点距离相机的深度。

该点投影到像平面后得到图像点：p = (x,y)。

相机光心到像平面的距离为焦距 f。在水平和竖直方向分别利用相似三角形，可以得到：
```text
Xc / Zc = x / f
Yc / Zc = y / f
``` 
所以 
```text
x = f * Xc / Zc
y = f * Yc / Zc
``` 
所以可以从这式子推导出反投影公式前面两条：Xc = x*Zc / f ; Yc = y *Zc / f。x=(u-cx) ; y=(v-cy) 。
