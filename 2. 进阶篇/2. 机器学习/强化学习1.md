# 强化学习入门 
强化学习一词如果对人工智能和具身智能比较感兴趣的同学可能会听说过，强化学习是机器人乃至人工智能训练和学习的一种重要的方法。

## 什么是强化学习 

简单来说，**强化学习（Reinforcement Learning，RL）**是指机器人通过与环境交互来实现目标和学习的一种计算方法。是一种**试错型学习**。  

智能体（Agent）:做决策的机器 

## 区别于有监督学习、无监督学习 
有监督学习、无监督学习、强化学习都是机器的三种学习方式，那他们之间有什么异同呢。

### 有监督学习 
**核心：给模型大量的数据+正确答案，让模型学会这两者之间的关系** 

人话就是，你小时候爸妈教你认识猫狗这两种动物，他们拿着印着猫/狗的识字卡片教你，告诉你这是猫，这是狗，经过训练你就可以知道什么是猫什么是狗。教一个模型识别猫猫和狗狗也是如此。

```text
     输入图片 → 神经网络 → 预测结果 → 与正确答案比较 → 计算误差 → 调整网络参数 
``` 

例子：YOLO模型训练，CNN  

有监督学习适合：目标检测、目标识别、目标分类、语义分割、姿态估计（RM估计步兵装甲板位姿）

### 无监督学习 
**核心：没人告诉模型正确答案，靠模型自己提取特征，归类。** 

给模型1000张车、人、狗图片，让模型自己分出三类。

人话：篮子里面有三种水果，苹果、香蕉、葡萄，里面水果有很多个；但你不认识这三种水果，也没老师告诉你这三种水果分别是什么。但是你靠着观察它们的特征把它们分成了三个类别（圆圆的红红的一类，黄黄的长长的一类，紫色的，一颗一颗的串起来的一类），但是你始终还是认不得里面的水果。 

例子：K-Means，雷达点云聚类，根据分割好的点云让模型自己归类出柱、台、梯结构。 

无监督学习适合：点云聚类、数据聚类、异常检测、特征提取 

### 强化学习 
**核心：无直接答案，靠机器自己不断试错，通过奖惩机制学习。**

让智能体不断与环境发生交互，通过奖惩机制学习如何行动。 

人话:
```text
学生：
我应该向左走吗？

老师：
-10分。

学生：
那我试试向右。

老师：
+5分。

学生：
看来向右更好。
```
强化学习适合：控制、路径决策、动作规划、复杂策略 

- 有监督、无监督均属于预测型的学习：根据数据预测所需输出（有监督）；生成数据实例（无监督） 

- 强化学习属于决策型学习：在动态环境中选择更优的行动，随着时间的推移最大化积累奖励。 


在上面，我们就对强化学习有了简单的了解了。

## 强化学习的三个方面 
- **感知**：在某种程度上可以感知自身的周围环境状态，例如给机器人加装相机，雷达，或者在机械臂末端加入力学传感器。
- **行动**：可以采取行动来影响状态或者达成目标；例如可以用机械臂抬起一个积木，但是如果机器没任何实际动作，那此时做出来的决策叫想法，而非行动。 
- **目标**：随着时间推移最大化积累奖励;例如在有限的时间内将最多的积木放在箱子里。

### 强化学习的基本术语 

- **智能体（Agent）**:即做决策的机器，可以是一个神经网络，也可以是一个自我迭代的决策算法 
- **环境（Environment）**：即智能体交互的对象，在训练时是仿真环境（模拟现实情境的环境），而真机上是现实环境。就像训练一个家居服务机器人，那它的环境就是客厅，厨房...环境是动态的，行动可以改变它，也就是你路过草丛时脚下的草会被踩塌。
- **奖励（Reward）**:是指环境在每一步给智能体的标量反馈，用来定义任务目标，智能体通过最大化长期积累奖励来学习策略。做对了就加分，做错了就扣分。
- **动作（Action）**：智能体的输出，通常对于机器人来说可能是关节电机的角度，轮子速度...而在外部看来表现出来是一组动作（例如左走右走拿东西）
- **观察（Observation）**: 智能体的输入，指智能体通过传感器或环境接口向外界获取到信息
  ```text
  摄像头 → 看到球的位置
  雷达 → 检测到前方有障碍物
  编码器 → 得到轮子转速
  IMU → 得到姿态
  ```
- **状态（State）**: 一种用于确定接下来发生的事情（A,R,O）的信息。是能够完整描述当前环境情况，并足以帮助智能体做出决策的信息。 
  ```text
  位置：(2, 3)
  速度：1 m/s
  朝向：30°
  球的位置：(5, 6)
  障碍物位置：(...)
  ``` 
  这些信息共同描述了机器人当前所处的情况，就是状态。
- **历史（History）**:观察、奖励、行动的序列，一直到时间t为止的所有可观测变量，根据这个历史可以决定接下来发生什么。
  ```text
  Ht = ((O1,R1,A1),(O2,R2,A2)...(Ot-1,Rt-1,At-1),(Ot,Rt)) 

  状态是关于历史的函数：St = f(Ht)
  ``` 
- **策略（Policy，记作 $\pi$）**:智能体根据当前状态（或观察）决定应该采取什么动作的规则。“在什么情况下，我应该做什么”。数学上表示为**π(a∣s)**，表示在状态 s 下选动作 a 的概率。例如：
  ```text
  当前状态
  ↓
  机器人在球的左边
  ↓ 
  策略
  ↓
  向右移动
  ``` 

### 策略 
策略是状态到行动的映射，分为确定性策略和随机策略。  

- 确定性策略：$a = \mu(s)$   只要状态相同，动作就完全相同。
- 随机性策略：$a\sim \pi(a\mid s)$ 


一个误区：基于模型的强化学习和与模型无关的强化学习的根本区别在于学习过程中有没有环境模型。 基于模型的强化学习。策略（和/或）价值函数，环境模型。如迷宫游戏。模型无关的强化学习。策略（和/或）价值函数，没有环境模型。如Atari游戏的通用攻略。
  
(很搞笑的是机器通常会为了达成目标采取任何不要脸的手段，就像我看过的一篇论文里面讲过四足机器狗会为了减少摩擦对奖励积分的扣除会选择将四肢蜷缩起来行走)  



### 交互过程 
```text
       -----→智能体----- 
       |       ↑       |
  观察 |   奖励 |       |行动
 O_t   |   R_t |       | A_t 
       |       |       |
       ------环境 ←-----
```
智能体与环境进行交互，在t-1时刻，智能体做出了At-1的行动，影响了环境，环境状态改变，给予观察反馈即O_t，然后奖励函数根据动作给予奖励反馈R_t，智能体接收到O_t,R_t后调整策略，做出了A_t行动。然后环境获得行动A_t，给出观察O_{t+1}，给出奖励R_{t+1}。 

## 奖励函数和价值函数 
奖励函数和价值函数都是强化学习里面很重要的概念，用于观测智能体策略的优劣。在上面，我们了解到了强化学习需要给智能体进行奖励，让它朝着累积最多奖励的方向进行学习，同时也了解了奖励的基本概念。 

### 奖励函数 
简单来说，奖励函数就是环境给的“即是得分规则”，也就是要怎么做才能拿到奖励，奖励函数定义目标。

### 价值函数 
价值函数是智能体预测的“长期总得分”，评估当前状态/动作离目标有多好。是对未来累积奖励的预测，用于评估在给定的状态下，策略的好坏。

## 强化学习基本模型--多臂老虎机 

多臂老虎机是强化学习里面一个很经典很基础的数学模型。讲述的问题是，在你面前有 K 台老虎机，每个老虎机上都有一个拉杆，每个老虎机的获奖概率都不同，拉动一次拉杆，可能会获得10块钱奖励，也可能拿不到钱，我们在各根拉杆的奖励概率分布未知的情况下，从头开始尝试，目标是在操作 T 次拉杆后获得尽可能高的累积奖励。多臂老虎机模型没有“状态/观察”这复杂的环境模型。 

<img src="https://pic1.zhimg.com/80/v2-de3eeb3c1136b278f72df468078f97dc_hd.jpg" alt="D435i" style="width: 350px; height: 300px;">  

形式化描述：多臂老虎机可以被描述为一个元组$\langle \mathcal{A},\mathcal{R}\rangle$ 
- $\boldsymbol{a^i}$：第 i 号动作（拉杆），$a^i\in\mathcal{A}$
 
- $\mathcal{A}$：动作集合，一共 K 个可选动作 i=1,2,...,K

- $\langle \mathcal{A},\mathcal{R}\rangle$：**完整老虎机模型 = 动作集合 + 收益分布**

- $\boldsymbol{\mathcal{R}(r \mid a^i)}$：收益随机分布
 
- r：得到的即时收益(reward)

- $\mid a^i$：条件符号，代表：当执行动作 a^i 的前提下

- $\mathbb{P}(r \mid a^i)$：条件概率：选择动作a^i时，拿到收益r的概率 
- 收益（反馈）函数分布：$\boldsymbol{\mathcal{R}(r \mid a^i)}$ = $\mathbb{P}(r \mid a^i)$ 
  通常来说多臂老虎机拉下拉杆，例拉下摇杆a1，不是每次都固定获得5块，而是70%概率获得10块，30%概率什么都没有。$\boldsymbol{\mathbb{P}(r=10 \mid a^1)}$=0.7；$\boldsymbol{\mathbb{P}(r=0 \mid a^1)}$=0.3，这就是该动作的收益分布$\boldsymbol{\mathcal{R}(r \mid a^i)}$。 

python完整代码描述
```python
# 导入需要使用的库,其中numpy是支持数组和矩阵运算的科学计算库,而matplotlib是绘图库
import numpy as np
import matplotlib.pyplot as plt


class BernoulliBandit:     # 这个就是强化学习的简单环境
    """ 伯努利多臂老虎机,输入K表示拉杆个数 """
    def __init__(self, K): # 初始化该多臂老虎机，定义好参数
        self.probs = np.random.uniform(size=K)  # 随机生成K个0～1的数,作为拉动每根拉杆的获奖
        # 概率
        self.best_idx = np.argmax(self.probs)  # 获奖概率最大的拉杆
        self.best_prob = self.probs[self.best_idx]  # 最大的获奖概率（所有拉杆的概率都不会告诉给智能体）
        self.K = K

    def step(self, k):
        # 当玩家选择了k号拉杆后,根据拉动该老虎机的k号拉杆获得奖励的概率返回1（获奖）或0（未
        # 获奖）
        if np.random.rand() < self.probs[k]:  # 生成一个[0:1]的随机数，如果该随机数小于获奖概率则判定为获奖；反之没获奖；例如，拉下拉杆1时，获奖概率为0.7，生成随机数字0.5，则获奖；0.9则无奖
            return 1
        else:
            return 0


np.random.seed(1)  # 设定随机种子,使实验具有可重复性，修改随机种子改变生成的随机数
K = 10
bandit_10_arm = BernoulliBandit(K) # 这是一个十臂老虎机
print("随机生成了一个%d臂伯努利老虎机" % K)
print("获奖概率最大的拉杆为%d号,其获奖概率为%.4f" %
      (bandit_10_arm.best_idx, bandit_10_arm.best_prob))
```

```text 
随机生成了一个10臂伯努利老虎机
获奖概率最大的拉杆为1号,其获奖概率为0.7203
```
