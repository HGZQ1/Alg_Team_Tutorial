# 强化学习入门 

强化学习一词如果对人工智能和具身智能比较感兴趣的同学可能会听说过，强化学习是机器人乃至人工智能训练和学习的一种重要的方法。

## 什么是强化学习 

简单来说，**强化学习（Reinforcement Learning，RL）**是指机器人通过与环境交互来实现目标和学习的一种计算方法。是一种**试错型学习**。  那我们为什么需要强化学习呢，一个重要的原因是因为强化学习得到的模型可以有超人类的表现，让模型自己在环境中自己探索，相对于监督学习来说有更大的潜力。就像Alpha Go打败顶尖棋手、OpenAI机械臂翻魔方、游戏里面的人机队友。

强化学习并不是什么抽象的概念，就像自然界中的动物刚出生并不会知道如何站立，通过试错，一段时间后就学会站立、行走、跑步。就像最开始玩我的世界这一款游戏，没有教程就需要通过自己探索、试错，最终知道需要获取什么资源，需要到哪里获取什么资源，末地传送门怎么寻找，怎么打败末影龙通关。

智能体（Agent）:做决策的机器 

## 区别于有监督学习、无监督学习 
有监督学习、无监督学习、强化学习都是机器的三种学习方式，那他们之间有什么异同呢。

### 有监督学习 
**核心：给模型大量的数据+正确答案，让模型学会这两者之间的关系** 

人话就是，你小时候爸妈教你认识猫狗这两种动物，他们拿着印着猫/狗的识字卡片教你，告诉你这是猫，这是狗，经过训练你就可以知道什么是猫什么是狗。教一个模型识别猫猫和狗狗也是如此。

例子：YOLO模型训练，CNN  

有监督学习适合：目标检测、目标识别、目标分类、语义分割、姿态估计（RM估计步兵装甲板位姿）

### 无监督学习 
**核心：没人告诉模型正确答案，靠模型自己提取特征，归类。** 

给模型1000张车、人、狗图片，让模型自己分出三类。

例子：K-Means，雷达点云聚类，根据分割好的点云让模型自己归类出柱、台、梯结构。 

无监督学习适合：点云聚类、数据聚类、异常检测、特征提取 

### 强化学习 
**核心：无直接答案，靠机器自己不断试错，通过奖惩机制学习。**

让智能体不断与环境发生交互，通过奖惩机制学习如何行动。

## 强化学习的三个方面 
- **感知**：在某种程度上可以感知自身的周围环境状态，例如给机器人加装相机，雷达，或者在机械臂末端加入力学传感器。
- **行动**：可以采取行动来影响状态或者达成目标；例如可以用机械臂抬起一个积木，但是如果机器没任何实际动作，那此时做出来的决策叫想法，而非行动。 
- **目标**：随着时间推移最大化积累奖励;例如在有限的时间内将最多的积木放在箱子里。

### 强化学习的基本术语 

- **智能体（Agent）**:即做决策的机器，可以是一个神经网络，也可以是一个自我迭代的决策算法 
- **环境（Environment）**：即智能体交互的对象，在训练时是仿真环境（模拟现实情境的环境），而真机上是现实环境。就像训练一个家居服务机器人，那它的环境就是客厅，厨房...环境是动态的，行动可以改变它，也就是你路过草丛时脚下的草会被踩塌。
- **奖励（Reward）**:是指环境在每一步给智能体的标量反馈，用来定义任务目标，智能体通过最大化长期积累奖励来学习策略。做对了就加分，做错了就扣分。
- **动作（Action）**：智能体的输出，通常对于机器人来说可能是关节电机的角度，轮子速度...而在外部看来表现出来是一组动作（例如左走右走拿东西）
- **观察（Observation）**: 智能体的输入，指智能体通过传感器或环境接口向外界获取到信息
  ```text
  摄像头 → 看到球的位置
  雷达 → 检测到前方有障碍物
  编码器 → 得到轮子转速
  IMU → 得到姿态
  ```
- **状态（State）**: 一种用于确定接下来发生的事情（A,R,O）的信息。是能够完整描述当前环境情况，并足以帮助智能体做出决策的信息。 
  ```text
  位置：(2, 3)
  速度：1 m/s
  朝向：30°
  球的位置：(5, 6)
  障碍物位置：(...)
  ``` 
  这些信息共同描述了机器人当前所处的情况，就是状态。
- **历史（History）**:观察、奖励、行动的序列，一直到时间t为止的所有可观测变量，根据这个历史可以决定接下来发生什么。
  ```text
  Ht = ((O1,R1,A1),(O2,R2,A2)...(Ot-1,Rt-1,At-1),(Ot,Rt)) 

  状态是关于历史的函数：St = f(Ht)
  ``` 
- **策略（Policy，记作 $\pi$）**:智能体根据当前状态（或观察）决定应该采取什么动作的规则。“在什么情况下，我应该做什么”。数学上表示为**π(a∣s)**，表示在状态 s 下选动作 a 的概率。例如：
  ```text
  当前状态
  ↓
  机器人在球的左边
  ↓ 
  策略
  ↓
  向右移动
  ``` 

### 策略 
策略是状态到行动的映射，分为确定性策略和随机策略。  

- 确定性策略：$a = \mu(s)$   只要状态相同，动作就完全相同。
- 随机性策略：$a\sim \pi(a\mid s)$ 


一个误区：基于模型的强化学习和与模型无关的强化学习的根本区别在于学习过程中有没有环境模型。 基于模型的强化学习。策略（和/或）价值函数，环境模型。如迷宫游戏。模型无关的强化学习。策略（和/或）价值函数，没有环境模型。如Atari游戏的通用攻略。
  
(很搞笑的是机器通常会为了达成目标采取任何不要脸的手段，就像我看过的一篇论文里面讲过四足机器狗会为了减少摩擦对奖励积分的扣除会选择将四肢蜷缩起来行走)  



### 交互过程 
```text
       -----→智能体----- 
       |       ↑       |
  观察 |   奖励 |       |行动
 O_t   |   R_t |       | A_t 
       |       |       |
       ------环境 ←-----
```
智能体与环境进行交互，在t-1时刻，智能体做出了At-1的行动，影响了环境，环境状态改变，给予观察反馈即O_t，然后奖励函数根据动作给予奖励反馈R_t，智能体接收到O_t,R_t后调整策略，做出了A_t行动。然后环境获得行动A_t，给出观察O_{t+1}，给出奖励R_{t+1}。 

## 奖励函数和价值函数 
奖励函数和价值函数都是强化学习里面很重要的概念，用于观测智能体策略的优劣。在上面，我们了解到了强化学习需要给智能体进行奖励，让它朝着累积最多奖励的方向进行学习，同时也了解了奖励的基本概念。 

### 奖励函数 
简单来说，奖励函数就是环境给的“即是得分规则”，也就是要怎么做才能拿到奖励，奖励函数定义目标。

### 价值函数 
价值函数是智能体预测的“长期总得分”，评估当前状态/动作离目标有多好。是对未来累积奖励的预测，用于评估在给定的状态下，策略的好坏。 

### 探索与利用 

是强化学习中trial-and-error中的必备技术，尽可能获得更好都策略的一种方式。基于目前策略获取目前最优收益or尝试更多可能的策略。就像我们平时上课时就在想中午吃什么好，是吃一直都觉得好吃的黄焖鸡，还是去探索解锁新的餐厅。探索利用好则不会一味陷入**局部最优**。

## 强化学习基本模型--多臂老虎机 

多臂老虎机是强化学习里面一个很经典很基础的数学模型。讲述的问题是，在你面前有 K 台老虎机，每个老虎机上都有一个拉杆，每个老虎机的获奖概率都不同，拉动一次拉杆，可能会获得10块钱奖励，也可能拿不到钱，我们在各根拉杆的奖励概率分布未知的情况下，从头开始尝试，目标是在操作 T 次拉杆后获得尽可能高的累积奖励。多臂老虎机可视为只有一个状态的环境，没有需要建模的状态转移，动作只决定本次奖励的分布。

<img src="https://pic1.zhimg.com/80/v2-de3eeb3c1136b278f72df468078f97dc_hd.jpg" alt="D435i" style="width: 350px; height: 300px;">  

形式化描述：多臂老虎机可以被描述为一个元组$\langle \mathcal{A},\mathcal{R}\rangle$ 
- $\boldsymbol{a^i}$：第 i 号动作（拉杆），$a^i\in\mathcal{A}$
 
- $\mathcal{A}$：动作集合，一共 K 个可选动作 i=1,2,...,K

- $\langle \mathcal{A},\mathcal{R}\rangle$：**完整老虎机模型 = 动作集合 + 收益分布**

- $\boldsymbol{\mathcal{R}(r \mid a^i)}$：收益随机分布
 
- r：得到的即时收益(reward)

- $\mid a^i$：条件符号，代表：当执行动作 a^i 的前提下

- $\mathbb{P}(r \mid a^i)$：条件概率：选择动作a^i时，拿到收益r的概率 
- 收益（反馈）函数分布：$\boldsymbol{\mathcal{R}(r \mid a^i)}$。离散收益时，$\mathbb{P}(R=r\mid A=a^i)$ 是该分布在 $r$ 处的概率。
  通常来说多臂老虎机拉下拉杆，例拉下摇杆a1，不是每次都固定获得5块，而是70%概率获得10块，30%概率什么都没有。$\boldsymbol{\mathbb{P}(r=10 \mid a^1)}$=0.7；$\boldsymbol{\mathbb{P}(r=0 \mid a^1)}$=0.3，这就是该动作的收益分布$\boldsymbol{\mathcal{R}(r \mid a^i)}$。 

python完整代码描述
```python
# 导入需要使用的库,其中numpy是支持数组和矩阵运算的科学计算库,而matplotlib是绘图库
import numpy as np
import matplotlib.pyplot as plt


class BernoulliBandit:     # 这个就是强化学习的简单环境
    """ 伯努利多臂老虎机,输入K表示拉杆个数 """
    def __init__(self, K): # 初始化该多臂老虎机，定义好参数
        self.probs = np.random.uniform(size=K)  # 随机生成K个0～1的数,作为拉动每根拉杆的获奖
        # 概率
        self.best_idx = np.argmax(self.probs)  # 获奖概率最大的拉杆
        self.best_prob = self.probs[self.best_idx]  # 最大的获奖概率（所有拉杆的概率都不会告诉给智能体）
        self.K = K

    def step(self, k):
        # 当玩家选择了k号拉杆后,根据拉动该老虎机的k号拉杆获得奖励的概率返回1（获奖）或0（未
        # 获奖）
        if np.random.rand() < self.probs[k]:  # 生成一个[0:1]的随机数，如果该随机数小于获奖概率则判定为获奖；反之没获奖；例如，拉下拉杆1时，获奖概率为0.7，生成随机数字0.5，则获奖；0.9则无奖
            return 1
        else:
            return 0


np.random.seed(1)  # 设定随机种子,使实验具有可重复性，修改随机种子改变生成的随机数
K = 10
bandit_10_arm = BernoulliBandit(K) # 这是一个十臂老虎机
print("随机生成了一个%d臂伯努利老虎机" % K)
print("获奖概率最大的拉杆为%d号,其获奖概率为%.4f" %
      (bandit_10_arm.best_idx + 1, bandit_10_arm.best_prob))  # 展示时使用从1开始的编号
```

### 收益计算
在描述了这个多臂老虎机的环境模型后，我们还需要一个函数来帮忙统计我们每次拉拉杆后取得的收益。
- **最大化累计收益**：
  $$G_T=\sum_{t=1}^{T}R_t,\qquad \max_{\pi}\;\mathbb{E}_{\pi}[G_T]$$
  其中 $R_t\sim\mathcal{R}(\cdot\mid A_t)$ 是第 $t$ 次拉杆得到的即时收益。目标是在有限的 $T$ 次操作中，让累计收益（通常是其期望）尽可能大。
- **收益估计**：

设选择动作 $a$ 时的真实期望收益为
$$q_*(a)=\mathbb{E}[R_t\mid A_t=a].$$
最优拉杆为 $a^*=\arg\max_{a\in\mathcal A}q_*(a)$，但这个值对智能体未知。智能体可以用历史样本估计它：
$$Q_t(a)=\frac{1}{N_t(a)}\sum_{i=1}^{t}\mathbf{1}(A_i=a)R_i,$$
其中 $N_t(a)=\sum_{i=1}^{t}\mathbf{1}(A_i=a)$ 是动作 $a$ 被选择的次数；当 $N_t(a)=0$ 时，可用初始值 $Q_0(a)=c$ 代替。对伯努利老虎机，$q_*(a)$ 就是该拉杆的获奖概率。

#### 增量式收益估值

直接保存全部历史奖励会占用越来越多的内存。样本平均值可以用增量形式计算。第 $n$ 次选择动作 $a$、得到奖励 $R_n$ 后：
$$Q_n(a)=Q_{n-1}(a)+\frac{1}{n}\bigl(R_n-Q_{n-1}(a)\bigr).$$
因此只需保存当前估值和计数器 $n$。更一般地，也可以使用常数步长：
$$Q(a)\leftarrow Q(a)+\alpha\bigl(R_t-Q(a)\bigr),\quad 0<\alpha\le1.$$
当环境平稳时取 $\alpha=1/N(a)$ 等价于样本平均；环境变化时使用固定 $\alpha$ 能让估值更快跟随新数据。

对应的更新流程如下（每次只更新本轮被选中的拉杆）：
```text
初始化：N(a)=0，Q(a)=c
重复 t=1,...,T：
  按策略选择 A_t，观察奖励 R_t
  N(A_t) ← N(A_t)+1
  Q(A_t) ← Q(A_t) + [R_t-Q(A_t)]/N(A_t)
``` 

### 算法框架 
我们现在有了环境模型和收益计算，我们就可以开始搭建算法框架了
1. 初始化：$Q(a^i) = c$, $N(a^i) = 0$, t = 1...T（初始化期望收益Q(a^i),初始化计数器N(a^i),计数器就是统计拉了多少次拉杆的，t也是差不多表示拉了多少次拉杆）
2. 主循环：t = 1 : T

   ① 利用策略$\pi$选取某个动作a （我们需要采取什么策略来进行拉杆呢，这是我们需要寻找的问题）

   ② 获取收益：$r_t = \text{bandit.step}(a)$

   ③ 更新计数器：N(a) = N (a) +1

   ④ 更新估值：Q(a) = Q(a) + 1/N(a)[ r_t - Q(a) ]

3. 目标：使长远收益最大化 


#### 懊悔函数

为了统计策略带来的失误（当前选择的拉杆与最大收益拉杆的收益差），我们引入一个叫**懊悔函数**的东西。 

**懊悔（regret）衡量**“没有选择最优拉杆”带来的损失。

**决策的期望收益**：$Q(a_i) = \mathbb{E}_{r-p(r|a^i)}[r|a^i]$，

该算式表示的就是真实期望，是环境属性，也就是每根拉杆的期望收益，例如拉杆a_1：70%拿10块钱，30%拿0块钱，则该拉杆的期望收益为Q（a_1）=10 x 0.7+0 x 0.3 = 7，也就是说该拉杆的期望收益是7元。 

算式意思是$Q(a_i)$表示在选择动作$a^i$的前提下，即时收益r（r服从 $\mathbb{P}(r \mid a^i)$：条件概率：选择动作a^i时，拿到收益r的概率 ）的期望。

**最优收益**：$Q* = max_{a^i∈A} Q(a^i)$ ,"$max_{a^i∈A} Q(a^i)$"表达就是Q（a^i）最大值，a^i属于$\mathcal{A}$这个动作集合。 

**决策与最优决策的收益差**：$R(a^i) = Q* -Q(a)$ 

前 $T$ 步的累计伪懊悔为
$$\operatorname{Regret}(T)=\sum_{t=1}^{T}\rho_t
 =Tq_*(a^*)-\sum_{t=1}^{T}q_*(A_t).$$
代码中的 `best_prob - probs[k]` 正是在伯努利老虎机上累加这个期望差值。由于实际奖励带有随机性，也可以定义实现懊悔 $Tq_*(a^*)-\sum_tR_t$；绘制算法曲线时通常使用累计伪懊悔，结果更稳定。

```python
class Solver:
    """ 多臂老虎机算法基本框架 """
    def __init__(self, bandit):
        self.bandit = bandit
        self.counts = np.zeros(self.bandit.K)  # 每根拉杆的尝试次数
        self.regret = 0.  # 当前步的累积懊悔
        self.actions = []  # 维护一个列表,记录每一步的动作
        self.regrets = []  # 维护一个列表,记录每一步的累积懊悔

    def update_regret(self, k):
        # 计算累积懊悔并保存,k为本次动作选择的拉杆的编号
        self.regret += self.bandit.best_prob - self.bandit.probs[k]
        self.regrets.append(self.regret)

    def run_one_step(self):
        # 返回当前动作选择哪一根拉杆,由每个具体的策略实现
        raise NotImplementedError

    def run(self, num_steps):
        # 运行一定次数,num_steps为总运行次数
        for _ in range(num_steps):
            k = self.run_one_step()
            self.counts[k] += 1
            self.actions.append(k)
            self.update_regret(k)
```

### 贪心算法（Greedy）

贪心策略始终选择当前估值最大的动作：
$$A_t=\arg\max_{a\in\mathcal A}Q_t(a).$$
它利用当前已知信息很充分，但几乎不主动探索，第一次误判后可能永久锁定次优拉杆。因此通常先让每根拉杆至少被选择一次，或使用较大的乐观初始值 $c$；估值相同的时候应随机打破并列，以免固定的动作编号产生偏置。

下面的示例使用后文定义的 `Solver` 基类；实际运行时请先执行基类定义。

```python
class Greedy(Solver):
    """先试每根拉杆一次，再始终选择当前估值最大的拉杆"""
    def __init__(self, bandit, init_prob=0.0):
        super().__init__(bandit)
        self.estimates = np.full(self.bandit.K, init_prob, dtype=float)

    def run_one_step(self):
        untried = np.flatnonzero(self.counts == 0)
        if len(untried) > 0:
            k = np.random.choice(untried)
        else:
            best = np.flatnonzero(self.estimates == self.estimates.max())
            k = np.random.choice(best)
        r = self.bandit.step(k)
        self.estimates[k] += (r - self.estimates[k]) / (self.counts[k] + 1)
        return k
```

### $\varepsilon$-greedy 算法

以概率 $\varepsilon$ 随机探索，以概率 $1-\varepsilon$ 选择估值最大的动作：
$$A_t=\begin{cases}
\text{随机选择动作},&概率\ \varepsilon,\\
\arg\max_a Q_t(a),&概率\ 1-\varepsilon.
\end{cases}$$
固定 $\varepsilon$ 实现简单，能持续发现可能变好的拉杆，但即使已经找到最优拉杆，仍会进行探索，使后期懊悔大致保持线性。文档后面的 `EpsilonGreedy` 类就是该算法的实现；其中增量更新使用了 $1/N(a)$ 的步长，`init_prob=1.0` 是针对伯努利奖励的乐观初始值，也能帮助早期探索。

### $\varepsilon$-衰减算法

训练早期需要多探索，后期则应更多利用当前最优估值。令探索率随时间下降，例如指数衰减：
$$\varepsilon_t=\max\bigl(\varepsilon_{\min},\varepsilon_0\cdot\text{decay}^{\,t-1}\bigr),$$
也可使用 $\varepsilon_t=c/(c+t)$。设置 $\varepsilon_{\min}>0$ 可以保留少量探索，避免过早陷入次优动作；衰减过快则会失去探索机会。

下面的类继承后文的 `EpsilonGreedy`，只需在每次交互后更新探索率。

```python
class EpsilonDecayGreedy(EpsilonGreedy):
    def __init__(self, bandit, epsilon=1.0, epsilon_min=0.01,
                 decay=0.995, init_prob=1.0):
        super().__init__(bandit, epsilon=epsilon, init_prob=init_prob)
        self.epsilon_min = epsilon_min
        self.decay = decay

    def run_one_step(self):
        k = super().run_one_step()
        self.epsilon = max(self.epsilon_min, self.epsilon * self.decay)
        return k
```

比较 Greedy、固定 $\varepsilon$-greedy 和 $\varepsilon$-衰减算法时，可将它们分别运行多次并绘制 `regrets` 曲线；曲线越低，表示累计懊悔越小。


### 算法框架
1. 初始化：Q(a^i) = c, N(a^i) = 0, t = 1...T
2. 主循环：t = 1 : T

   ① 利用策略$\pi$选取某个动作a

   ② 获取收益：$r_t = \text{bandit.step}(a)$

   ③ 更新计数器：N(a) = N (a) +1

   ④ 更新估值：Q(a) = Q(a) + 1/N(a)[ r_t - Q(a) ]

3. 目标：使长远收益最大化

```python
class Solver:
    """ 多臂老虎机算法基本框架 """
    def __init__(self, bandit):
        self.bandit = bandit
        self.counts = np.zeros(self.bandit.K)  # 每根拉杆的尝试次数
        self.regret = 0.  # 当前步的累积懊悔
        self.actions = []  # 维护一个列表,记录每一步的动作
        self.regrets = []  # 维护一个列表,记录每一步的累积懊悔

    def update_regret(self, k):
        # 计算累积懊悔并保存,k为本次动作选择的拉杆的编号
        self.regret += self.bandit.best_prob - self.bandit.probs[k]
        self.regrets.append(self.regret)

    def run_one_step(self):
        # 返回当前动作选择哪一根拉杆,由每个具体的策略实现
        raise NotImplementedError

    def run(self, num_steps):
        # 运行一定次数,num_steps为总运行次数
        for _ in range(num_steps):
            k = self.run_one_step()
            self.counts[k] += 1
            self.actions.append(k)
            self.update_regret(k)

class EpsilonGreedy(Solver):           #智能体
    """ epsilon贪婪算法,继承Solver类 """
    def __init__(self, bandit, epsilon=0.01, init_prob=1.0):
        super(EpsilonGreedy, self).__init__(bandit)
        self.epsilon = epsilon
        #初始化拉动所有拉杆的期望奖励估值
        self.estimates = np.array([init_prob] * self.bandit.K)

    def run_one_step(self):
        if np.random.random() < self.epsilon:
            k = np.random.randint(0, self.bandit.K)  # 随机选择一根拉杆
        else:
            best = np.flatnonzero(self.estimates == self.estimates.max())
            k = np.random.choice(best)  # 选择期望奖励估值最大的拉杆，并随机打破并列
        r = self.bandit.step(k)  # 得到本次动作的奖励
        self.estimates[k] += 1. / (self.counts[k] + 1) * (r - self.estimates[k])   #更新estimates--->学习
        return k


def plot_results(solvers, solver_names):
    """生成累积懊悔随时间变化的图像。输入solvers是一个列表,列表中的每个元素是一种特定的策略。
    而solver_names也是一个列表,存储每个策略的名称"""
    for idx, solver in enumerate(solvers):
        time_list = range(len(solver.regrets))
        plt.plot(time_list, solver.regrets, label=solver_names[idx])
    plt.xlabel('Time steps')
    plt.ylabel('Cumulative regrets')
    plt.title('%d-armed bandit' % solvers[0].bandit.K)
    plt.legend()
```
